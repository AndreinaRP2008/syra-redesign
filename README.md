# Syra Coffee — Redesign Challenge ☕

Conceptual redesign of the Syra Coffee digital experience.

> This is an independent portfolio project. Syra Coffee and its brand assets belong to their respective owners.

## Challenge

Redesign Syra's web experience without losing what makes the brand recognizable: good coffee, accessibility, simplicity, specialty coffee, and a strong everyday ritual.

The central design challenge is:

**How can we make Syra feel more playful, expressive and memorable while keeping the experience clear, premium and conversion-focused?**

## Process

1. Research
2. UX audit
3. Information architecture
4. Design direction
5. Design system
6. UI design
7. Development
8. Interaction and motion
9. Responsive / accessibility / performance polish

## Project principles

- Less noise, more hierarchy.
- Cartoon does not mean childish.
- Every visual element should have a purpose.
- The shop must remain easy to use.
- The homepage should introduce Syra, not contain the entire business.
- Coffee stories should become easier to understand visually.
