## UX principle

The homepage is deliberately short. Product catalogue depth, detailed coffee stories and educational content belong to dedicated pages.

The user should always have two obvious paths:

**I know what I want → Coffee / search → product → cart**

**I don't know what I want → Coffee finder → recommendation → product → cart**
