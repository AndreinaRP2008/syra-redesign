# Information Architecture

The homepage is a guided entry point, not the whole catalogue.

## Navigation

- Coffee
- Find a shop
- Subscription
- Guides
- Search
- Account / App
- Cart

## Homepage

1. Hero
2. Featured coffee
3. Coffee finder
4. From farm to cup
5. Find a shop
6. Subscription
7. Footer

## Core paths

**Know what I want:** Coffee → filter/search → product → cart

**Need help choosing:** Coffee finder → recommendation → product → cart

**Want the physical experience:** Find a shop → city/location → shop
