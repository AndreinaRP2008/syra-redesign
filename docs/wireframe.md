# Syra Coffee — Wireframe Challenge

## Goal

Translate the UX strategy into a low-fidelity responsive structure before visual styling.

## Desktop order

1. Header
2. Hero
3. Featured coffee
4. Coffee finder
5. From farm to cup
6. Shop finder
7. Subscription
8. Footer

## Mobile rule

The same hierarchy remains. Sections become single-column and interactive elements must remain thumb-friendly.

## Component inventory to define

- Header
- Navigation
- Hero
- CTA button
- Coffee card
- Coffee badge / tag
- Coffee finder step
- Recommendation card
- Story step
- Shop card
- Map / location selector
- Subscription CTA
- Footer
- Cart indicator

## Next

Build the actual low-fidelity wireframe and test whether the homepage still feels short, clear and commercially useful before introducing illustration and colour.
